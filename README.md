# TravelTrucks

A web application that helps travelers find and choose the perfect camper van for their next trip.

It turns the overwhelming process of van rental into a simple, enjoyable browsing experience by answering the key questions:

- Which camper fits my trip - a van, a fully integrated motorhome, or an alcove?
- What features and equipment does each vehicle actually have?
- Which one matches my budget and travel style?

## What the app provides:

- Catalog of camper vans - browse a curated list of vehicles with photos, price, and key specs.
- Filtering - narrow down the catalog by vehicle type, equipment (AC, kitchen, TV, bathroom, etc.), and other features to quickly find a good match.
- Detailed vehicle pages - full description, gallery, technical specifications, and reviews for each camper.
- Favorites - save interesting vans to a personal shortlist to compare later.
- Booking request form - reach out to reserve a chosen camper directly from its page.
- Core value - makes camper rental research calm and straightforward by bringing all the essential information into one clean interface.
